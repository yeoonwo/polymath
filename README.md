# PolyMath — VS Code

## Cara menjalankan
1. Ekstrak folder `PolyMath-VSCode` jika menggunakan ZIP.
2. Buka folder tersebut di Visual Studio Code.
3. Buka `index.html` di browser, atau gunakan ekstensi **Live Server**:
   - Klik kanan `index.html`
   - Pilih **Open with Live Server**

## File
- `index.html` — kerangka halaman aplikasi
- `style.css` — desain responsif dan palet warna pastel
- `script.js` — navigasi dan logika interaktif

## Catatan
- Versi ini menggunakan HTML, CSS, dan JavaScript tanpa framework.
- Login adalah simulasi lokal, belum terhubung database/server.
- Materi, simulator, flashcard, dan kuis berjalan di browser.
- Internet diperlukan untuk memuat font Nunito dari Google Fonts; aplikasi tetap bisa berjalan jika font tidak termuat.
